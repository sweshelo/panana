# Panana

電波人間のRPG ゲームエディタ

## Works

- WORKLOG.md を作業ログとする。実施した作業についてはここに記録する。
- STATE.md をタスクファイルとする。計画を立てた後、着手出来る準備としてタスクを分割する。意図、ステップ、完了条件などを簡潔に記す
- 過去の作業の内容などは WORKLOG を辿れば良い。WORKLOG と STATE は同時に書き込み、どちらに何を書くか整理して出力する (どちらに何を書いたか、再読み込みによるトークン消費防止)

## Rules

- サブエージェントは原則起動しない。並列化でき、かつ戻り値が500トークン以内に収まる探索のみ最大2体まで
- 各サブには読んでよいファイルを列挙する。docs/** の一括読み、WORKLOG.md 全文読み、生の逆アセンブリ/バイナリダンプの貼付は禁止
  - これらの作業を要する時、`agy` を利用する
- 作業前に「読む文書は X と Y」と宣言させる。それ以外が必要になったら理由を言ってから読む
- テスト・grep の出力はファイルに落とし、tail / 要約だけをコンテキストに入れる
- 単純作業や大規模コンテキストを要求するタスクは `agy` (旧: Gemini CLI / 現: Antigravity)を呼び出して活用する
  - 目的は **あなたの** トークンを節約することにあり、外部のエージェントを呼び出している。
  - この際、立ち上げるエージェントにはコンテキストの節約や読む文書の制限を指示しない。

作業後、git commit して コミットハッシュ付きで WORKLOG.md を更新する。STATE.mdには、次のタスクを記述する。
