# Panana

Pananaとは、ハワイ語で羅針盤の意。

電波人間のRPG シリーズのデータを、ブラウザの中で読んで調べ・編集する静的サイトです。サーバーは要りません。

## 対応タイトル

| タイトル | 内部名 | 対応 |
|---|---|---|
| 電波人間のRPG (初代) | honolulu | マップの閲覧、ワールドマップ (船着場の島)・モンスター・アイテム・ショップ・メッセージの閲覧と編集、MOD の書き出し |
| 電波人間のRPG2 (v1.1.0) | kahara | マップ・ワールドマップ (地形・入口、3D)・図鑑・メッセージ・イベントなどの編集と MOD の書き出し |
| 電波人間のRPG3 | oahu | ワールドマップ (地形・入口・範囲、3D)・図鑑・メッセージ・群れ・アクションの閲覧と編集 (対応を進めています) |
| 電波人間のRPG FREE! | lanai | 読み取り |

ページごとの詳しい機能と操作は [Features.md](Features.md) にあります。

## 使い方

```bash
bun install
bun run dev        # http://localhost:5173/
bun run build      # dist/ (静的ファイル。サーバー不要)
```

ROM は次のどれかを選んで開きます。

1. 復号済みの CIA (`.cia`)
2. 復号済みの NCCH (`.cxi` / `.app`)
3. 展開済みのフォルダ (RomFS のルートのファイルと `code.bin`)

RPG3 と RPG FREE! は Base と Update の CIA を一緒に選んでください。Update の修正を含めて読みます。初代は Update が知られていないので、Base だけです。
複数の作品の CIA をまとめて選ぶと、同時に開けます (上のバーの「ROM」で一覧・切り替え・追加ができます)。
暗号化されたダンプは読めません (GodMode9 などで復号してください)。

## 基本の流れ

- ROM を開くと、まずマップのページを出します。上のバーでページを切り替えます。
- 編集内容は自動で保存され、次に開いたときに読み込むかを聞きます。
- 「書き出し…」で変更の一覧と検証結果を確認し、zip または MOD フォルダへの書き込みを選びます。
- 「土台の MOD」で既存の MOD (elpulse の `mod/out` など) を読み込むと、その上に編集を重ねて書き出せます (全作品)。

## ROM データについて

ROM 由来のデータはリポジトリにもアプリにも含みません。利用者のダンプから、ブラウザの中だけで読み取ります。
読み取ったファイルと変換済みのモデルは、その端末の IndexedDB にキャッシュします。
