# Panana
Pananaとは、ハワイ語で羅針盤の意。

電波人間のRPG2 (v1.1.0, TID 00040000000A7900) のデータを、ブラウザの中で読んで調べ・編集する静的サイトです。
上のバーでページを切り替えます (URL は `#/map/<マップ名>`、`#/monsters/<行>`、`#/items/<ID>`、`#/shops/<店ID>`、`#/groups/<行>`、`#/actions/<行>`、`#/messages/<ダンジョン>.<行>` または `#/messages/0x<ID>`)。

- **マップ編集**: ダンジョンのマップを 2D / 3D を見ながら編集し、LayeredFS 用の MOD (`00040000000A7900/romfs/A90C8038` など) として書き出す。
  マップの BGM・出現する敵も右ペインで見られる。
- **モンスター図鑑**: 全モンスターの能力・ドロップ・ワザ・耐性 (効果つき、編集できる) と、出現するマップ。
- **アイテム図鑑**: 全アイテムの分類・価格・効果・説明 (欄ごとの表) と、手に入る場所 (お店・宝箱・モンスターのドロップ)。
  買値・売値・☆・上限・使用効果 (アクション)・上限で置き換わるアイテムを編集できる。板一枚のモデルは正面から表示する。
- **ショップ**: 全 18 店の品揃え (店での並び順・分類・買値) と店員のメッセージ。アイテム名で、それを売る店を探せる。
  品揃えはドラッグ&ドロップで追加・削除・並べ替えができる (ShopItem を 49A43B63 と 1D37838B の両方に書き出す)。
- **群れ**: 敵の群れ (monsterGroup) の一覧と、それを使うマップ。候補のモンスター・重み・数を編集でき、写して新しい群れも作れる。
- **アクション**: アクション (actionData) の一覧。アイテムの使用効果の内容・引数 (分かっている欄と生データ) と、使うアイテム・ワザとして持つモンスター。
- **メッセージ**: NPC の会話・看板 (本棚など) のメッセージの一覧と、置かれているマップ。会話の 4 つの台詞がどの進行で出るかも表示する。本文を編集でき (ルビ・差し込みを展開したプレビューつき)、同じメッセージを使うほかの行も分かる。ID を指定して任意のメッセージも開ける。マップ編集のインスペクタでも、選んだ NPC・看板の本文をその場で編集できる。

書き出し (上のバー) には、マップ・イベントの表・宝箱の中身・モンスター・群れ・アイテム・店の品揃えの変更がまとめて入ります。

設計: `../elpulse/docs/map-editor-design.md`、データ構造: `../elpulse/docs/map.md`、敵と BGM: `../elpulse/docs/encounters.md`。

ROM 由来のデータはリポジトリにもアプリにも含めません。利用者のダンプから、ブラウザの中だけで読み取ります
(読み取ったファイルと変換済みのモデルは、その端末の IndexedDB にキャッシュします)。

## 使い方

```bash
bun install
bun run dev        # http://localhost:5173/
bun run build      # dist/ (静的ファイル。サーバー不要)
```

入力 (どれか 1 つ):
1. 復号済みの CIA (`.cia`)
2. 復号済みの NCCH (`.cxi` / `.app`)
3. 展開済みのフォルダ (RomFS のルートのファイル `A90C8038` などと `code.bin`)

暗号化されたダンプは読めません (GodMode9 などで復号してください)。

### 操作

| 操作 | 内容 |
|---|---|
| V 選択・移動 | タイルを選ぶ (Shift で追加)。点 (出入口・宝箱など) をドラッグで移動 |
| B タイルを置く | パレットで選んだタイル (種類・文字・向き) を置く。ドラッグで連続 |
| E タイルを消す | |
| M 範囲選択 | Ctrl+C / Ctrl+V (マウスのあるセルが左上) / Del / Shift+矢印で中身ごと移動 |
| G 敵の出現セル | 区画 6 のセルを付け外し |
| R / Shift+R | 向きを回す (選択中のタイル、またはブラシ) |
| [ / ] | 文字 (バリエーション) を切り替える |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し (マップごと) |
| Ctrl+D | 選択中の点を複製 |

- 3D: 右ドラッグで回転、中ドラッグで移動、ホイールで拡大。左クリックは 2D と同じ編集操作 (地面 y=0 上のセル)。
- 天井 (マテリアル名 *ceil*) は既定で隠します。「高さで切る」で壁の上部も切れます。
- 編集内容は自動で IndexedDB に保存され、次に開いたときに読み込むかを聞きます。
- 「書き出し…」: 変更の一覧と検証結果を出し、zip または MOD フォルダへの直接書き込み (File System Access API) を選べます。
  書き出すのは変更したファイルだけです: マップ → `A90C8038`、宝箱の「中身の表の行」やモデルの上書き → ダンジョンのイベントのアーカイブ (`79B881BB` など)、宝箱の中身・メッセージ → `56562135` (マスター)。
- マップ名は「山のどうくつ 地下2階」のように表示します (コード `D01B02001` も併記)。出入口の行き先マップ・地点も名前で選べます。
- 3D ではタイルに加えて、階段・扉・門・宝箱・置物・ワープホール・NPC などをゲームのモデルで表示します (「オブジェクトのモデル」で切り替え)。

### 土台の MOD

ヘッダーの「土台の MOD」で、既存の MOD のフォルダ (elpulse の `mod/out`: `romfs/*` と `code.ips`) を読み込むと、その上で編集します。
- マスター (`56562135`、アイテム名や宝箱の中身) などはその MOD のものを使い、書き出しの zip にはその MOD の全ファイル (`romfs/*`、`exefs/code.ips`) も入ります。zip 1 つで配置が済みます。
- code.ips に汎用スイッチ (elpulse `docs/events.md` §7) があれば「汎用スイッチあり」と表示し、スイッチと柵を置けるようにします。

### イベント・ギミック

仕組みは elpulse の `docs/events.md`、全イベントの一覧は `docs/reference/events.md`。
- レコードを選ぶと、右ペインにイベントの行 (EventObject) の種類と、種類ごとの欄 (会話・看板のメッセージ本文、宝箱の中身など)、生データを出します。
- マップの右ペインの「イベントの一覧…」: ダンジョンの全イベントの行と、それを使うマップ・レコード。クリックでそのレコードへ移動します。
- スイッチと対象を線で結びます (汎用スイッチは実線、ゲームのスクリプトにある組は点線)。
- ゲームの「スイッチで扉が開く」は、ダンジョンと行番号ごとにコードに書かれたスクリプト (種類 0x24) で、データでは作れません。自由に作るには、汎用スイッチ入りの土台の MOD を読み込み、「追加」の「スイッチと柵」を使います。
  - 1 回目のクリックで柵 (区画 3 の種類 17)、2 回目で、それを開けるスイッチ (区画 5 の種類 2、イベントの種類 0x30) を置きます。
  - 右ペインで開ける対象 (2 つまで) と開き方 (柵 / 扉) を変えられます。スイッチと対象は同じマップに置きます。

### 宝箱・ギミックの追加

左ペインの「追加」で、置くものを選んでマップをクリックします (Esc で終わる)。
- 宝箱: ダンジョンのイベントの表 (EventObject) に新しい行、treasureGroup に新しい中身の行を作ります。中身は最初、同じダンジョンの宝箱の写しです。
- ダメージ床・凍った床 (区画 1)、置物 (区画 2、mapObject の行を選ぶ)。
- ギミック: ゲーム中の同じ種類のもの (スイッチ・回復の泉・穴・ワープホール・扉など) をひな形に、レコードとイベントの行を写します。動き (つながる扉や行き先など) は写し元の設定のままなので、右ペインのイベントの行の生データや行き先で直してください。
- 複製 (Ctrl+D) も、イベントの行 (宝箱なら中身の行も) を新しく作るので、元と状態を共有しません。
- 状態 (開けた・押した) はセーブ変数 0x8E の「ダンジョンの基準 (mapGroup +0x1A) + 枠 (EventObject +0x44)」に入ります。行と枠はダンジョンごとに mapGroup +0x1C 個まで (多くのダンジョンで 10 前後の空き) で、超える追加はできません。

### 出現する敵・BGM (マップの右ペイン)

何も選んでいないときの右ペインの下に出ます。
- BGM・効果音: ダンジョンの mapData の [4] フィールド、[5] 戦闘、[6] 足音 (soundData の行)。名前はダンプの `sound/sound.bcsar` から引きます (展開済みのフォルダで開いた場合は番号だけ)。
- 出現する敵: 区画 6 のヘッダー = マップの群れ (monsterGroup のハッシュ)。選び直すと書き出しに入ります。群れの候補 (先頭 = マップで見える敵と 3 体目、仲間 = 2・4 体目) を、重みの割合と数で出します。
- セルごとに別の群れを持つセルは、群れごとにまとめて出します。モンスター名は図鑑へのリンクです。

### モンスター図鑑

MonsterParameter (185 行) を elpulse の `tools/gen_reference.py` と同じ読み方で展開し (`src/game/monsters.ts`)、名前・説明は MonsterDesign (`2713402F`) から引きます。
左の一覧は名前・ワザ・ドロップで検索し、「マップに出る」「ボス・変身」・ダンジョンで絞り込めます。出現する場所は、今の (編集中の) マップの区画 6 から計算し、マップ名をクリックするとマップ編集で開きます。

耐性 (25 個、−9〜+10) は、属性・状態異常・能力ダウン・突然死に分けて、値ごとの効果を出します (`../elpulse/docs/battle.md` §6.4・§6.5)。
- 属性: ダメージの倍率 (BattleParameter +0x08 の表: −9 = ×4 … 0 = ×1 … +9 = ×0.1)。+10 は無効 (×0。モンスターの生成時にフラグが立つ)。
- 状態異常・能力ダウン・突然死: 付与率の係数 (BattleParameter [0x67 + 値 + 9]: −9 = 200% … +9 = 0%) と、基本の率 100 / 50 / 25% のワザでの付与率。+10 は +9 に丸められる (0%)。
- 属性と状態異常はレーダーチャートでも出し、軸の点をドラッグして値を変えられます (点線 = 元の値)。

値は選び直せます (MonsterParameter のビットを書き換え、マスター `56562135` として書き出し)。変えた値は枠の色で分かり、「このモンスターの変更を元に戻す」で戻せます。編集は自動で保存します (マップ編集の「戻す」の対象外)。

### 図鑑のモデルと写真

一覧の各行に写真 (モデルを描いた縮小画像。見えた行から順に作り、IndexedDB に保存) を、詳細にドラッグで回せる 3D ビュー (ホイールで拡大、「写真を保存」で PNG) を出します。
- モンスター: MonsterDesign +0x10 = モデルとモーションの bcres、+0x14 = 色違いのテクスチャの bcres (どちらも `470D2848`)。テクスチャは名前で差し替える。写真は静止姿勢で描きます。
- 3D ビューでは、モデルに入っているモーション (CGFX の骨格アニメ) を再生できます (左下: モーションの選択・再生 / 一時停止・フレーム)。最初は `001_…_wait` (ミュージアムと戦闘の待機、アニメ番号 0x41)。モーションの名前の横に、ゲームでの使われ方 (0x49 攻撃を受けた など) を出します。
  名前の先頭 4 文字が同じマテリアルアニメ (目のパターン) も一緒に動かします (ゲームと同じ照合)。1 秒 60 フレーム。解析と形式は `docs/monster-motion.md`。
- アイテム: itemData +0x20 の bcres (`1D37838B` 道具、`302996EB` 装備、`56562135`)。服の柄 (596〜696) はテクスチャだけなので、その画像を出します。

### 群れ

マスターの monsterGroup (1 行 = 先頭の候補 5 個 +0x00、仲間の候補 5 個 +0x14、各 {u16 モンスター, u8 重み, u8 数のコード}、+0x28〜 未解析) を一覧します (`src/pages/groups.ts`)。
- 左の一覧はモンスターの名前で検索し、「マップで使う」「どのマップも使わない」「変更した」で絞り込めます。使うマップは、今の (編集中の) マップの区画 6 (ヘッダーとセル) から計算します。
- 一覧はモンスターを写真 (図鑑と同じ縮小画像) で出します。候補のモンスターは写真の一覧 (ダイアログ) から選び直し、重み (1〜255)・数も変えられ、「＋ 追加」(5 個まで) と「×」で増減できます。割合は重みから計算します。変更はマスター `56562135` として書き出し、編集は自動で保存します。
- 「写して新しい群れを作る」: 今の群れを写した行を monsterGroup の末尾に足し、索引に新しいハッシュを入れます。マップ編集の右ペイン「出現する敵」で選べます。
- マップ編集・モンスター図鑑の群れの表から「群れ #N を開く」でこのページへ移れます。

### アクション

マスターの actionData を一覧します (`src/game/actions.ts`、`src/pages/actions.ts`)。既定は「アイテムの効果 (種類 2)」で、「アイテムが使う」「モンスターのワザ」「すべて」に切り替えられます。
- 分かっている欄: +0x00 の w0 (bit1-2 種類、bit3-6 効果の種別、bit13-15 付与の段階、bit29-31 使える場面)、+0x04 名前のメッセージ、+0x18 / +0x1A 量 (s16)。ほかの欄は生データ (u32・s16 × 2) で出します。
- 参照: そのアクションを使う道具 (itemData +0x24) と、ワザとして持つモンスター (MonsterParameter +0x3C)。アイテム図鑑の効果とモンスター図鑑のワザからリンクします。

### アイテム図鑑

itemData の名前・説明・分類 (+0x2C)・☆・買値 / 売値・上限・上限に達したときの置き換え先と、消耗品の効果 (+0x24 のアクション: HP / AP 回復の量、使える場面) を出します。
手に入る場所: お店 (ShopItem、`49A43B63`)、宝箱 (今のマップの区画 4 → EventObject → treasureGroup、中の確率つき)、落とすモンスター。装備の値 (+0x2D / +0x2E) は未解析なので数値だけです。

### 宝箱の中身

宝箱 (区画 4) を選ぶと、右ペインに中身 (アイテム・重み・確率) を一覧で出します。区画 4 の +0 = ダンジョンの EventObject の行、その +0x08 = 中身の表 (treasureGroup) の行、その行に最大 10 個のアイテム {アイテム, 重み}。
開けると、並んだアイテムから重みに比例して 1 つ選ばれます。
- 「変更…」: 中身の表の全行を中身つきで一覧するダイアログで、別の行を選ぶか、今の中身を写した新しい行を作ります。行を共有している宝箱の数も出ます。
- アイテムはクリックで差し替え、「＋ 追加」で一覧表 (名前・分類で絞り込み) から選んで足し、「×」で外します。
- 中身はマスター (`56562135`) にあります。アイテム MOD (`elpulse/mod`) も `56562135` を置き換えるので、両方使うときは「土台の MOD」で `mod/out` を読み込んでください。

分かったこと (設計書からの補足):
- mapResource の行 = `[0] モデルのアーカイブ, [1] テクスチャのアーカイブ (469B3DC6), [2] その中のテクスチャ (bcres), [3] 空のモデル`。
  タイルのモデルはテクスチャを持たず、[2] の共有テクスチャを名前で参照する。
- CGFX の頂点バッファは 0x40000002 (インターリーブ)、その属性が 0x40000001、固定値の属性が 0x80000000。
- モデルは陰影を頂点カラーに焼き込んでいる (法線がない) ので、ライティングなしで描く。頂点カラーのアルファは不透明な面では使わない。
- 回転: 種類 7 (部屋の辺) の回転 0 のモデルは -Z (北) 側に壁がある。three.js では `rotation.y = -rot × 90°`。
- マップ表 (0x4C3AFC) の +0x10 (タイルセットの上書き) は、ダンジョンのマップではすべて 0 (上書きなし)。
- マップ DB のサイズ 0 のエントリは、次のブロックと同じオフセットを持つ。再構築では (オフセット, サイズ) の順に並べると元とバイト一致する。
- ダンジョン名は mapGroup +0x14 の u16 (u32 で読むと K / M / S 系が引けない)。
- オブジェクトのモデルは mapObject (マスター) の行。区画ごとの決め方、宝箱・EventObject・mapChara は `../elpulse/docs/map.md` §6・§8〜§10、実装は `src/game/objects.ts`。
- CGFX のボーンの world 行列は空のことが多いので、拡大・回転・移動を親から合成する (門の枠や宝箱のふたの位置)。
- マテリアルは PICA のテクスチャ合成 (TEV 6 段)・アルファテスト・ブレンドをシェーダーで再現する (`src/cgfx/tev.ts`)。例: ひび割れの貼り付けは乗算 (白 = 変化なし)、M_pack は 2 枚目のテクスチャの赤をアルファにしてアルファテストで抜く。フラグメントライティングは未対応 (白として扱う)。
- テクスチャのデータは上の行から並ぶが UV は v = 0 が下なので、上下を反転して渡す。

## テスト

```bash
python test/golden/export_golden.py   # ../elpulse の展開済みデータから test/golden/golden.json を作る
bun test
```

`rom.test.ts` は `ROM_CIA` (既定 `../elpulse/00040000000A7900.cia`) と `golden.json` がないときはスキップします。
- code.bin (BLZ の展開) が ctrtool の結果と一致
- 全 205 マップの名前・ダンジョン・階・区画のハッシュとサイズ、D01B02001 / D02B02002 のタイルと区画 3/4/5/8 が mapdump.py と一致
- LZ10 の圧縮結果が gsarc.lz10_compress とバイト一致
- 無編集で書き出したマップ DB・アーカイブが元とバイト一致、編集時は A2C14C00 以外のエントリが一致
- バニラのマップで検証が何も出さず、壊した編集は検出する
