# RPG FREE! (lanai) 書き出し MOD の実機検証

Issue #109。PR #106 の MOD 書き出しは往復テストとブラウザ確認まで済んでいて、ゲームが受け付けるかは未確認。ROM が要るので、検証は ROM を持つ環境(実機 / Citra 系エミュレータ)で行う。

## 準備

1. 復号済みの Base / Update CIA を用意する(`test/env.ts` の `LANAI_BASE` / `LANAI_UPDATE`、既定は `roms/free-base.cia` / `roms/free-update.cia`)。
2. テスト MOD を作る。1 つの zip に編集 1 つなので、失敗した仕組みが分かる。

   ```
   bun scripts/lanai-test-mods.ts roms/free-base.cia roms/free-update.cia lanai-test-mods
   ```
3. zip を LayeredFS の MOD として読み込む(`0004000000125D00/romfs/...`)。必ず未編集のセーブデータで始め、各 MOD は単独で試す。
4. 起動しない / フリーズ / 文字化けは「NG」。ログや症状を記録する。

## チェックリスト

| MOD | 編集 | 確認すること | 結果 |
|---|---|---|---|
| `m1-ability-row` | モンスター 41 に能力行をコピー追加(表末尾)、HP 9999 | 起動する。たからばこぞうと戦闘でき、HP が 9999 | |
| `m2-action-row` | ActionData の行を表末尾に複製して skill2 に差す | 戦闘で従来どおり「箱に隠れる」動作をする | |
| `m3-transform-target` | 複製した変身アクションの変身先を 45 に | 隠れたとき 42 ではなく 45 に変身する(系統 29/30、+0x50 の先読みが効く) | |
| `p1-tile-in-place` | タイル 1 枚を同サイズで差し替え(対照) | マップ D01001B01 でそのタイルだけ変わる | |
| `p2-record-added` | 出口レコードを 1 つ複製(区画が伸びる) | マップが開く。他のレコード/タイルがずれない | |
| `p3-record-removed` | 出口レコードを 1 つ削除(区画が縮む) | 同上。削除した出口が消える | |

タイルの増減(区画サイズが変わる)は、`p1` が同サイズなので `p2` / `p3` のレコード増減で区画のサイズ変更を確認する。タイル自体の増減を試すなら、エディタで空きセルにタイルを置いて書き出す(スクリプトは未対応)。

## 結果の反映

結果は naauao の `lanai/` 文書の確度(確定 / 推定)に反映する: monsters.md §1・§3・§9(能力行・アクション・変身)、map.md(区画サイズ変更・レコード増減)。#110 と #113 はこの結果に依存する。
